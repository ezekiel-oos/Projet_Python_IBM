# Python Project: Tesla & GameStop Stock Analysis

This project is part of the IBM Data Science course.  
It uses **Python**, **yfinance**, **pandas**, **matplotlib**, and **BeautifulSoup** to analyze stock market data and revenue information for Tesla and GameStop.

## Project Content
- **Question 1**: Importing the required libraries  
- **Question 2**: Downloading GameStop data with `yfinance`  
- **Question 3**: Resetting the index and displaying the first rows  
- **Question 4**: Extracting Tesla revenue data from Macrotrends  
- **Question 5**: Extracting GameStop revenue data from Macrotrends  
- **Question 6**: Visualizing Tesla stock prices (2019–2021)  
- **Question 7**: Visualizing GameStop stock prices (2019–2021)  

## Results
- Creation of DataFrames for Tesla and GameStop revenues.  
- Comparative plots of closing prices between 2019–2021.  
- Basic analysis of stock market trends.  

## Technologies Used
- Python 3  
- Jupyter Notebook  
- Libraries: `yfinance`, `pandas`, `matplotlib`, `requests`, `BeautifulSoup`
